# Experiment log

Presets store starting states, not sound impressions or the path that led
there. For a tool built around playful exploration of parameter spaces,
the journey is often more interesting than the end state -- hence a
separate, informal log.

## Convention

One file per session: `Docs/experiments/YYYY-MM-DD_short-title.md`. No
fixed template, but useful to include:

- Which preset/starting configuration (reference to a Presets/ file, or
  roughly described if improvised)
- What was changed (parameters, live interventions, order)
- Sonic observation, even if subjective/vague -- better noted imprecisely
  than not at all
- Whether it's worth turning into a preset in `Presets/factory/`

## Scratch folder

`Docs/experiments/scratch/` is gitignored -- for raw notes during a
session, before you decide whether something belongs in the actual log.
Prevents every half-finished note from creating a commit.
